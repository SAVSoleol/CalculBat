Logique SOC Battery Sizer

SOC technique fixe : 5 %.

Résidentiel / PME :
- 0-5 % : réserve technique non utilisée;
- 5-100 % : autoconsommation.

C&I :
- 0-5 % : réserve technique non utilisée;
- 5 % -> frontière choisie : réserve Peak Shaving;
- frontière -> 100 % : autoconsommation.

Le Battery Sizer dimensionne l'autoconsommation uniquement sur la zone au-dessus
de la frontière Peak Shaving. Le calcul de Peak Shaving reste dans l'outil dédié.
