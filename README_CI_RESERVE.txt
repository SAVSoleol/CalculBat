Battery Sizer - réserve Peak Shaving uniquement en C&I

Résidentiel :
- aucun réglage Peak Shaving;
- 0 à 100 % disponible pour l'autoconsommation.

PME :
- aucun réglage Peak Shaving;
- 0 à 100 % disponible pour l'autoconsommation.

C&I / Industrie :
- réglage « Réserve Peak Shaving (%) »;
- 0 -> réserve % = énergie réservée aux pointes;
- réserve % -> 100 % = énergie disponible pour l'autoconsommation;
- affichage des kWh réservés et des kWh d'autoconsommation;
- ligne de réserve sur le graphique SOC.

Le Battery Sizer ne calcule pas l'économie Peak Shaving.
Ce calcul reste dans Peak Shaving Simulator.
